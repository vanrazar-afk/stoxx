# VOLTIX — אפליקציית דירוג וניתוח מניות (Android + iOS)

אפליקציית מידע ולימוד שמדרגת את כל 500 מניות S&P 500 לפי מודל כמותי (כל 5 דקות בזמן המסחר, כל שעה מחוצה לו) ומבליטה את 50 המובילות, עם ציון 1–100 שבנוי משלושה שלישים שווים (טכני · פונדמנטלי · סנטימנט), רמות יעד וסטופ טכניות, ותיק מניות אישי.

```
stoxx/
├── engine/      מנוע הדירוג היומי (Node + TypeScript)  → מפיק daily.json
├── app/         אפליקציית המובייל (Expo SDK 58 / React Native, עברית RTL)
├── docs/        מדיניות פרטיות, צ'קליסט לחנויות
└── .github/workflows/daily-ranking.yml   הרצה אוטומטית: כל 5 דקות במסחר, כל שעה מחוץ למסחר
```

---

## 🚀 התחלה מהירה בחינם (אפליקציית ווב עם נתונים אמיתיים, מתעדכנת אוטומטית, בלי מפתחות API)

כל הכלים חינמיים ולא צריך שום מפתח: GitHub (קוד + הרצה אוטומטית + אחסון האתר), Yahoo Finance (מחירים, דוחות, יעדי אנליסטים, מועדי דוחות וחדשות), Google News (כותרות מ-Bloomberg, Reuters, CNBC, MarketWatch, Barron's, Morningstar ועוד) ורשימת S&P 500 פתוחה.

1. **פתיחת חשבון GitHub**: נרשמים ב-github.com.
2. **יצירת ריפו**: לוחצים על **New repository**, נותנים שם `stoxx`, בוחרים **Public** ולוחצים Create.
3. **העלאת הקבצים**: לוחצים **Add file → Upload files** וגוררים את **תוכן** התיקייה `stoxx`. אם התיקייה `.github` לא עולה, יוצרים את הקובץ ידנית דרך **Add file → Create new file** בשם `.github/workflows/daily-ranking.yml` ומדביקים את התוכן.
4. **הפעלת האתר**: נכנסים ל-**Settings → Pages**, ותחת Source בוחרים **GitHub Actions**.
5. **הרצה ראשונה**: בלשונית **Actions** בוחרים **Ranking + web app** ולוחצים **Run workflow** (כ-10 דקות).
6. **פתיחת האפליקציה**: `https://<שם-המשתמש>.github.io/stoxx`. זו אפליקציית ווב (PWA): בטלפון בוחרים "התקנת אפליקציה" / "הוספה למסך הבית". מדריך מלא, כולל העלאה ל-Google Play דרך PWABuilder, נמצא במסמך המדריך.

מכאן הדירוג מתעדכן לבד: כל 5 דקות בזמן המסחר בוול סטריט (מחירים וטכני; חדשות ופונדמנטלי פעם בשעה), וכל שעה כשהבורסה סגורה. כל 500 מניות S&P 500 מדורגות. אופציונלי: Secret בשם `ANTHROPIC_API_KEY` לסיווג סנטימנט מדויק יותר.

> Yahoo Finance הוא מקור לא רשמי: מתאים לבדיקות ולשימוש אישי, ולפני השקה מסחרית צריך להחליף אותו בספק עם רישיון (המנוע תומך ב-FMP דרך Secret בשם `FMP_API_KEY`).

## 1. סקר שוק — מה עובד אצל המובילים

| אפליקציה | מה מייחד אותה | מה לקחנו | מה שיפרנו |
|---|---|---|---|
| **Seeking Alpha – Quant Rating** | ציון לכל מניה + ציוני פקטורים A–F (שווי, צמיחה, רווחיות, מומנטום, עדכוני תחזיות) | פירוק הציון לפקטורים גלויים | הכול בעברית, חינם בבסיס, טבלה עם נקודות לכל פקטור |
| **TipRanks – Smart Score** | ציון 1–10 משמונה פקטורים, כולל אנליסטים וחדשות | שילוב סנטימנט חדשות בציון | מקורות החדשות שקופים (10 מקורות, כל כתבה מסווגת ומקושרת) |
| **Zacks Rank** | דירוג 1–5 לפי עדכוני תחזיות רווח, רשימות מובילות | רשימת "המובילות" כמסך הבית | עדכון יומי עם תנועה בדירוג (▲▼ / חדש) |
| **Danelfin – AI Score** | ציון 1–10 משולב טכני/פונדמנטלי/סנטימנט | שלושת אותם עמודי תווך | חלוקה שווה וגלויה (33.3 לכל שליש) במקום "קופסה שחורה" |
| **Simply Wall St / Yahoo / Delta** | ויזואליזציה נקייה, תיק אישי | תיק, רשימת מעקב, גרפים | ציון תיק משוקלל ופיזור ענפי |

**היתרונות התחרותיים של VOLTIX:**
1. **שקיפות מלאה** — כל נקודה בציון מוסברת בטבלה (המתחרים מציגים בעיקר ציון סופי).
2. **יעד יציאה + סטופ לכל מניה** — רוב המתחרים לא נותנים רמות פעולה טכניות.
3. **עברית מלאה ו-RTL** — אין מתחרה משמעותי בעברית.
4. **פרטיות** — אין חשבון, אין שרת משתמשים; התיק נשמר במכשיר.

## 2. איך מחושב הציון (מתודולוגיה v1.1)

**טכני (עד 33.3)** — `engine/src/scoring/technical.ts`
| פקטור | נקודות |
|---|---|
| מחיר מעל ממוצע 200 | 15 |
| ממוצע 50 מעל ממוצע 200 | 10 |
| התקרבות לממוצע 100 מלמעלה (0–3%) | 20 |
| נרות אדומים ואחריהם יום ירוק (3+ אדומים = מקסימום) | 20 |
| RSI(14) מאוזן / יציאה ממכירת יתר | 15 |
| היסטוגרמת MACD מתהפכת למעלה | 10 |
| מחזור ביום הירוק מעל ממוצע 20 | 10 |

**פונדמנטלי (עד 33.3)** — `fundamental.ts` — הכול **ביחס לחציון הענף** (ראייה רחבה של השוק שבו החברה פועלת): P/E מול הענף (25), PEG (15), צמיחת הכנסות מול הענף (15), צמיחת EPS (10), שולי רווח מול הענף (10), חוב/הון (10), תשואת FCF (10), ROE (5).
**קרבה לדוח רבעוני:** הנקודות שנצברו מופחתות ביחס לקרבת הדוח — עד −50% ביום הדוח, ובאופן ליניארי עד 0 כשנותרו 30 יום ומעלה (דוח = סיכון לתנודה חדה).

**סנטימנט (עד 33.3)** — `sentiment.ts` — כותרות 7 ימים מ-10 המקורות: Reuters, Bloomberg, WSJ, Financial Times, CNBC, MarketWatch, Barron's, Yahoo Finance, Seeking Alpha, Benzinga.
- רק חדשות טובות → מקסימום. חדשות רעות דומיננטיות → תקרה של 20% מהשליש.
- חדשות רעות משוקללות ×1.5, חדשות טריות ומסוכנויות ידיעות שוקלות יותר.
- כתבה חיובית בודדת היא ראיה חלשה, לכן הציון מתקרב לניטרלי עד שיש ~3 כתבות (חדשות רעות לא מרוככות).
- סיווג: מילון מונחים פיננסי כברירת מחדל; עם `ANTHROPIC_API_KEY` הסיווג נעשה ע"י Claude (מדויק בהרבה).

**יעד וסטופ** — `levels.ts`: סטופ = 2×ATR מתחת למחיר (או מתחת לממוצע 100 אם קרוב יותר). יעד = ההתנגדות הקרובה (שיא 60 יום / 52 שבועות) אם היא נותנת לפחות 1.5R, אחרת 2R, עם תקרה של 3R.

## 3. הרצה מקומית

```bash
# מנוע (נתוני דמו)
cd engine && npm install && npm test && npm run demo     # → out/daily.json

# אפליקציה
cd app && npm install
npx expo start            # סרקו את ה-QR באפליקציית Expo Go בטלפון
npx expo start --web      # תצוגה בדפדפן
```

> RTL מלא נאכף ב-build אמיתי (פלאגין expo-localization עם `forcesRTL`). ב-Expo Go ייתכן שתצטרכו לסגור ולפתוח את האפליקציה פעם אחת.

## 4. מעבר לנתונים אמיתיים

1. **פתיחת חשבונות API**
   - [Financial Modeling Prep](https://site.financialmodelingprep.com) — מחירים יומיים, פרופיל, יעדי אנליסטים.
   - [Finnhub](https://finnhub.io) — מדדים פונדמנטליים, חדשות לפי חברה (כולל מקור), יומן דוחות.
   - (אופציונלי) [Anthropic API](https://console.anthropic.com) לסיווג סנטימנט.
2. **⚠️ רישיון הפצה**: תוכניות אישיות/חינמיות **לא מתירות** להציג את הנתונים למשתמשי אפליקציה. צריך תוכנית מסחרית/Display אצל כל ספק. זה הסעיף הקריטי ביותר בתקציב.
3. בדיקה מקומית: `FMP_API_KEY=... FINNHUB_API_KEY=... UNIVERSE_LIMIT=10 npm run daily` — ודאו ששמות השדות בתגובות תואמים (`providers/live.ts`).
4. **אוטומציה**: העלו את הריפו ל-GitHub, הוסיפו Secrets (`FMP_API_KEY`, `FINNHUB_API_KEY`, `ANTHROPIC_API_KEY`), משתנה `DATA_BASE_URL` (כתובת ה-Pages), והפעילו GitHub Pages ← Source: GitHub Actions. ה-workflow ירוץ כל 5 דקות בזמן המסחר בניו יורק וכל שעה כשהבורסה סגורה.
5. באפליקציה: הגדירו `EXPO_PUBLIC_DATA_URL` (ב-`eas.json`) לכתובת `daily.json`. מצב הדמו נעלם אוטומטית.

## 5. העלאה לחנויות — מה חייבים

**Apple App Store**
- [ ] חשבון Apple Developer **ארגוני** (חברה בע"מ + מספר D-U-N-S). סעיף 5.1.1(ix) בהנחיות של אפל דורש שאפליקציות בתחום השירותים הפיננסיים יוגשו ע"י ישות משפטית ולא ע"י מפתח פרטי.
- [ ] האפליקציה **לא** מבצעת מסחר ולא מנהלת כספים. זה חשוב, כי סעיף 3.2.1(viii) מגביל אפליקציות מסחר לגופים מורשים. בהערות לבודק כתבו: "Educational stock research tool. No trading, no brokerage, no account."
- [ ] מדיניות פרטיות ב-URL ציבורי (תבנית ב-`docs/privacy-policy.md`).
- [ ] App Privacy: "Data Not Collected" (כל עוד אין אנליטיקס/חשבונות).
- [ ] דירוג גיל 17+ (מידע פיננסי) + הדיסקליימר בתיאור ובאפליקציה ✅.
- [ ] מניפסט פרטיות ✅ (`app.json`).
- [ ] אם בעתיד יתווספו חשבונות משתמש — חובה מחיקת חשבון מתוך האפליקציה (קיים כבר "מחיקת כל הנתונים").

**Google Play**
- [ ] Financial features declaration (חובה לכל אפליקציה): לסמן את סוג הפיצ'רים הרלוונטי (מעקב תיק / מידע פיננסי) ולא "Financial advice".
- [ ] Data safety form: אין איסוף נתונים.
- [ ] בחשבון אישי חדש: בדיקה סגורה (Closed testing) עם 12 בודקים במשך 14 יום לפני הפצה לכולם.
- [ ] Target API level עדכני (Expo SDK 58 מטפל בזה).

**Build והגשה**
```bash
cd app
npx eas-cli@latest login
npx eas-cli@latest build --platform all --profile production
npx eas-cli@latest submit --platform ios
npx eas-cli@latest submit --platform android
```
לפני כן: החליפו `bundleIdentifier`/`package` (`com.voltix.app`), אייקון וספלאש ב-`assets/`, וכתובות פרטיות/תנאים/מייל ב-`app.json → extra`.

## 6. רגולציה בישראל ⚖️

חוק הסדרת העיסוק בייעוץ השקעות מגדיר "ייעוץ השקעות" כייעוץ לגבי הכדאיות של קנייה או מכירה של ניירות ערך, ומחייב רישיון. האפליקציה בנויה כך שתהיה **מידע כללי ולא מותאם אישית**:
- שמות זהירים: "50 המובילות לפי המודל", "יעד טכני", "סטופ" (במקום "כדאי לקנות").
- אין שאלון התאמה, אין התאמה לתיק של המשתמש, אין "קנה/מכור".
- דיסקליימר חובה בכניסה (עם אישור 18+), בכל מסך דירוג ובתיאור בחנות.
- המתודולוגיה גלויה ואחידה לכולם.

**לפני השקה: חובה להתייעץ עם עו"ד ניירות ערך.** רשימת "מניות לרכישה עם מחיר יציאה" נמצאת קרוב לקו, ולכן חשוב לקבל חוות דעת. אפשר גם לבקש מסגל רשות ניירות ערך עמדה שהשירות אינו ייעוץ השקעות; רשות ניירות ערך כבר פרסמה עמדות כאלה לשירותי מידע דומים. אם יבוצעו פרסומים של ביצועי עבר של הדירוג, יש לבדוק את ההוראות הרלוונטיות.
